# 项目文件夹说明

在 Windows 上日常使用只需找到项目根目录的三个入口：

| 文件 | 用途 |
| --- | --- |
| `start.cmd` | 双击构建并启动本机网站。运行期间保持窗口开启。 |
| `start-share.cmd` | 网站启动后，创建或显示正在运行的 Cloudflare 临时分享链接。 |
| `stop-share.cmd` | 关闭临时分享，网站仍可在本机使用。 |

## 根目录配置

| 文件 | 用途 |
| --- | --- |
| `README.md` | 快速启动、系统功能、外网分享和 Docker 部署说明。 |
| `index.html` | 网站的 HTML 入口，加载 React 客户端。 |
| `package.json` | 项目依赖及安装、开发、启动、构建、测试命令。 |
| `package-lock.json` | 锁定依赖版本，供 `npm ci` 使用。 |
| `tsconfig.json` | TypeScript 的编译和类型检查设置。 |
| `vite.config.ts` | 前端开发服务器、API 转发和生产构建设置。 |
| `.env.example` | 环境变量模板，用于首次创建本机配置。 |
| `.env` | 本机端口、数据库路径、模型密钥和运行参数。供服务读取，留在本机。 |
| `compose.yaml` | Docker Compose 的部署入口，配置端口、数据卷和健康检查。 |
| `.dockerignore` | 指定构建 Docker 镜像时排除的本机文件，如密钥和数据库。 |
| `.gitignore` | 指定 Git 不跟踪的依赖、构建产物和本机运行数据。 |

## 前端 `src/`

| 文件 | 用途 |
| --- | --- |
| `main.tsx` | 登录、用户首页、预警详情和后台各页面，以及相应的接口调用。 |
| `styles.css` | 页面、卡片、表格、弹窗和窄屏布局样式。 |
| `tasks.tsx` | 任务中心、进度统计和分来源采集详情。 |
| `task-labels.ts` | 任务类型、运行阶段和采集窗口的显示文案。 |
| `failures.tsx` | 失败明细列表和单篇模型分析重试入口。 |
| `failure-status.ts` | 前端的失败分类、统计口径及旧任务记录兼容。 |
| `risks.tsx` | 风险类别名称和颜色标签。 |

## 后端 `server/`

| 文件 | 用途 |
| --- | --- |
| `index.ts` | 读取环境配置，启动 HTTP 服务和定时任务，处理关闭。 |
| `app.ts` | 注册 API、校验账号权限并提供前端静态页面。 |
| `auth.ts` | 密码哈希与校验、会话令牌生成与哈希。 |
| `db.ts` | 打开 SQLite、创建基础表，并提供查询和事务函数。 |
| `init-admin.ts` | 首次安装时初始化开发者账号。 |
| `service.ts` | 数据库迁移、配置持久化、任务调度及进程间互斥。 |
| `collection.ts` | 计算各来源的采集窗口，组织采集任务、逐篇处理与进度记录。 |
| `source-registry.ts` | 内置来源、已保存的栏目清单及域名对应的解析方式。 |
| `crawler.ts` | 网页请求、链接规范化、栏目分页、正文提取和正文指纹。 |
| `pipeline.ts` | 解析附件，保存待分析和失败记录，处理去重及预警入库发布。 |
| `model.ts` | 调用模型接口，校验分类、结构和原文证据。 |
| `prompt.ts` | 系统内置的食品安全分析提示词。 |
| `failure-counts.ts` | 汇总当前的采集失败和模型分析失败。 |

## 脚本、部署、文档与验证

| 文件 | 用途 |
| --- | --- |
| `scripts/windows/start.ps1` | 检查 Node.js、准备配置与依赖，再构建并启动网站。 |
| `scripts/windows/start-share.ps1` | 检查本机服务、校验并运行隧道程序，记录分享进程和链接。 |
| `scripts/windows/stop-share.ps1` | 校验隧道进程身份并关闭隧道，清理临时分享状态。 |
| `deploy/Dockerfile` | 构建前端并打包生产环境所需的后端和依赖，由根目录的 Compose 配置引用。 |
| `docs/项目文件夹说明.md` | 本文件，供查找项目文件及用途。 |
| `tests/pipeline.test.ts` | 测试采集窗口、去重、附件、发布、失败重试、来源管理和权限等流程。 |
| `.github/workflows/ci.yml` | GitHub Actions 自动安装依赖、运行测试和构建。 |

## 本机运行及生成目录

| 路径 | 用途 |
| --- | --- |
| `data/food-safety.sqlite` | 默认生产数据库，保存账号、新闻、预警、任务和采集配置等。 |
| `data/food-safety.sqlite-wal`、`data/food-safety.sqlite-shm` | SQLite 运行时管理的日志与共享内存文件，可能随服务启动或关闭出现或消失。 |
| `dist/index.html`、`dist/assets/` | 前端生产页面及带版本指纹的 JS、CSS 等资源，由构建命令生成。 |
| `node_modules/` | npm 安装的第三方依赖文件，由锁文件管理。 |
| `.tools/cloudflared.exe` | Windows 临时分享使用的 Cloudflare 隧道程序。 |
| `.share/state.json` | 隧道进程编号、分享地址及启动时间，用于识别当前隧道。 |
| `.share/url.txt` | 最近一次生成的临时分享地址。 |
| `.share/tunnel.stdout.log`、`.share/tunnel.stderr.log` | 隧道运行与连接日志。 |
| `.git/` | Git 版本历史及仓库元数据。 |
